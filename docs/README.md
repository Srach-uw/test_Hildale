# Documentation Guide

Start with these files:

| Document | Purpose |
| --- | --- |
| `replication_status.md` | Current result, population counts, and unresolved inputs |
| `scientific_interim_assessment.md` | Detailed scientific interpretation and diagnostics |
| `full_factorial_validation_assessment.md` | Results from the completed 82-fit validation matrix |
| `combined_configuration_confirmation.md` | Completed nine-system combined configuration check |
| `author_clarification_request.md` | Reproduction products that are not available publicly |
| `final_public_data_boundary.md` | Final source, weighting, period, label, and density checks |
| `reproducibility_map.md` | Main claims linked to code, tests, and evidence |
| `data_availability.md` | Included data, excluded products, and licensing boundary |
| `../metadata/final_forensic_20260808/README.md` | Final Gilbert control, residual, QC, and weighting evidence |

Operational runbooks are retained for reproducibility:

| Document | Purpose |
| --- | --- |
| `gcp_no_charge_safety_checklist.md` | Billing and shutdown safeguards |
| `full_run_runbook.md` | ALDERAAN batch execution |
| `cloud_shell_quickstart.md` | Cloud Shell connection commands |
| `recovery_preflight_20260724.md` | Published-inventory recovery preparation |

The remaining dated audits and queue manifests describe earlier reconstruction
states. They are kept to show how decisions changed, but they are not current
sample definitions or headline results. In particular,
`alderaan_needed_validation.md`, `deep_audit_findings_2026-07-04.md`,
`gap_hunt_findings_2026-07-04.md`, and
`real_data_audit_findings_2026-07-04.md` must be read as historical records.
